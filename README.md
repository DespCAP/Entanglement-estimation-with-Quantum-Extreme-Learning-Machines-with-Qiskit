# Entanglement-estimation-with-Quantum-Extreme-Learning-Machines-with-Qiskit

Estimating the entanglement of mixed quantum states is a central problem in quantum 
information theory. Ref [1] introduces a quantum extreme learning machine (a quantum 
reservoir) to infer the entanglement parameter of two-qubit Werner states from 
measurement data. The aim of this project is to reproduce Fig.1 of the paper by generating 
Werner states that with random entanglement parameter p, applying noise with varying 
amplitudes, and training a regression model to predict the parameter p.

[1] G. Reyes-Barragán et al., Entanglement estimation of Werner states with a quantum 
extreme learning machine, [arXiv:2511.01387](https://arxiv.org/pdf/2511.01387) (2025).
